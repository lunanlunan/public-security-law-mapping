# 治安管理处罚法 2025 新旧条文对照

《中华人民共和国治安管理处罚法》2025 年修订、**2026-01-01 施行**，条文由旧版 119 条变为 **144 条**，条文号大量位移。

现状是：**没有一个可引用、可校验的完整对照表**，各地资料还在传旧条文号（例：殴打他人 旧 43 条 → 新 **51** 条；赌博 旧 70 条 → 新 **82** 条）。

这个仓库就想把这件事做干净：**逐条对照 + 可搜索 + 每条标明来源与核对状态**。

> ⚠️ 本项目为公益性质的资料整理，不构成法律意见。引用请以官方发布文本为准。

## 数据格式

`data/mapping.json`：

```json
{
  "items": [
    {
      "new_article": "51",
      "old_article": "43",
      "title": "殴打他人 / 故意伤害他人身体",
      "status": "已核",
      "source": "《治安管理处罚法》(2025修订) 第五十一条",
      "note": ""
    }
  ]
}
```

`status` 取值：

- `已核` —— 已比对官方文本
- `待核` —— 有来源线索但未逐字核对，**不要直接引用**
